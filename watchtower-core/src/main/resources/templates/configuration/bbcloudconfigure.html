checklistSet up Bitbucket for Watchtower
  1. Create an API token in Bitbucket Personal settings → Atlassian account settings → Security → API tokens. App passwords no longer work. Give it these scopes: read:repository:bitbucketread:pullrequest:bitbucket write:pullrequest:bitbucketread:webhook:bitbucket write:webhook:bitbucketdelete:webhook:bitbucket
  2. Enter workspace, email and token Your Atlassian account email is the username. The account must read the workspace's repositories, and be a workspace admin to register the webhook.
  3. Save Saving stores the settings only; nothing is called in Bitbucket yet.
  4. Test the connection Test connection, at the top of this page, checks the credential.
  5. Register the webhook So pull requests are scanned automatically. Registering also sets the webhook secret.
  6. Choose what happens when a scan blocks a PR Applies only after the webhook is registered.

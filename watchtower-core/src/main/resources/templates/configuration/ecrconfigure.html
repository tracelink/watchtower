checklistSet up Amazon ECR for Watchtower
  1. Find the region and registry Use the AWS Region of the registry and its registry ID, the 12-digit AWS account ID that owns it. Image scanning must be on for the registry.
  2. Create an access key for Watchtower An IAM user (or a key for an existing one) with these permissions. Registering creates a CloudFormation stack with an EventBridge rule, connection, API destination and IAM role, so the user also needs to create and delete those (EventBridge, IAM role and pass-role, and the Secrets Manager secret EventBridge makes for the connection). ecr:GetRegistryScanningConfigurationecr:DescribeImageScanFindings ecr:BatchDeleteImagecloudformation:CreateStack cloudformation:DescribeStackscloudformation:DeleteStack
  3. Save Saving stores the settings only; nothing is created in AWS yet.
  4. Test the connection Test connection, at the top of this page, checks the credential.
  5. Register the webhook Watchtower creates the stack so ECR scan results are sent to Watchtower.
  6. Choose what happens when a scan blocks an image Do nothing, or delete the image. Deleting an image can't be undone.
